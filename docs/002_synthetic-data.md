# 002 합성 데이터 생성과 점검 (1주차)

## 질문
학습용 표 데이터를 어떻게 만들 것인가? 만든 데이터가 실제 문서를 얼마나 닮았는가?

## 판단 근거
- 실제 한국어 표 + 정답 HTML 데이터셋은 공개된 것이 거의 없고, 사람이 수천 개를 라벨링할 수 없다.
- 표는 **HTML을 브라우저로 렌더링하면 이미지와 정답이 동시에** 생긴다 → 라벨 오류 0, 무한 생성 가능.
- 대신 "실제와 얼마나 비슷한가"가 성패를 가른다 → 생성 후 반드시 눈으로 점검하고 실제 문서와 비교.

## 고려한 대안
| 대안 | 장점 | 버린 이유 |
|---|---|---|
| PubTabNet 등 공개 데이터 | 대규모, 실제 문서 | 영문 논문 표 위주, 한국어 행정 문서 스타일·어휘와 거리가 멂 |
| 실제 PDF + Docling 출력을 정답으로 | 실제 분포 | Docling 오류가 그대로 정답이 됨 (실제로 검수에서 50개 중 40개가 구조가 틀려 있었음, 003) |
| 큰 VLM 출력을 정답으로 (증류) | 실제 분포 | 정답 품질이 교사 모델에 묶임, 평가 기준선과 겹침 |
| **합성 렌더링 (선택)** | 정답 완벽, 구조·스타일 통제 가능 | 실제와의 격차 → test-real로 측정 |

## 방법
`src/ko_table_vlm/generate.py`
1. **구조**: 헤더 1~3단(가중치 0.45/0.4/0.15), stub 열 1~2개, 헤더 그룹은 재귀 분할(colspan) + 하위가 없으면 rowspan, 본문 stub 그룹(rowspan 1~4), 합계 행(40%), 데이터 셀 병합(35% 표에서 8% 확률)
2. **내용**: 한국어 행정·통계 어휘(`content.py`) — 지역·부서·사업명, 숫자 표기(천 단위 쉼표, `△` 음수, `%`), 날짜 5가지 형식, 빈칸 기호(`-`, `…`), 셀 내 줄바꿈
3. **스타일**: 폰트 6종, 테두리 4종(전체/가로줄/외곽+헤더/없음), 헤더 배경 5종, 패딩·정렬·줄무늬·렌더 배율 1~2배 (`styles.py`)
4. **ood 스타일**: 학습에 없는 폰트 3종(Gowun 계열, 코딩 폰트), 테두리 2종(점선, 이중선), 헤더색 2종(주황, 진한 남색+흰 글씨)
5. **열화**(44%): 축소-확대, ±0.8° 회전, 흐림, 흑백, JPEG 압축
6. **검증**: 생성할 때마다 격자 일관성 assert, 모든 행에 그 행에서 시작하는 셀이 있는지 확인(없으면 HTML로 표현 불가 → 재생성)

## 미리보기 점검: 실제 문서와 비교 (2026-11-19)
무작위 train 6장과 test-real 50장을 나란히 보고 정리한 차이:

| 항목 | 합성 | 실제(국회예산정책처 문서) | 영향 |
|---|---|---|---|
| 헤더 셀 줄 수 | 거의 항상 1줄 | **2줄 헤더가 흔함** (`2023`/`결산`, `2026`/`예산안`) | 2줄 헤더를 두 칸으로 쪼개는 오류 (008 OTSL에서 결정적) |
| 헤더 패턴 | 무작위 조합 | **반복 패턴**: 연도별 `예산|수납`, `증감 → B-A | (B-A)/A`, `국회 심의결과 → 상임위 예비심사/본회의 수정 → 증액/감액/증감` | 실제 어휘 오독 (`예비비실적`, `수남`) |
| 세로 병합 길이 | 최대 4행 | **최대 17행** (`일반회계` 하나가 표 전체를 덮음) | 긴 rowspan 계산 실수 |
| 헤더 스타일 | 연한 배경 | **진한 청록/파랑 배경 + 흰 글씨**, 행 사이 점선 | 스타일 격차 |
| 열 의미 | 열 이름과 값이 무관 (`계약일` 열에 텍스트) | 의미가 일관 (연도 열에 숫자) | 언어 사전지식 활용 못 함 |
| 텍스트 셀 | 짧은 구 | 좁은 열에 **단어 중간 줄바꿈**(`영농형태양광기`/`반농가고소득작`) | 긴 셀 OCR |

## 해석
- 구조 다양성(병합·다단 헤더 비율)은 충분히 확보했다 — 쉬운 표가 6%뿐인 **어려운 분포**로 설계됨.
- 하지만 **실제 문서의 어휘·헤더 패턴·스타일은 반영이 약하다**. 이 차이가 이후 실험(006 real 결과, 008 OTSL 실패)의 원인으로 다시 등장한다.
