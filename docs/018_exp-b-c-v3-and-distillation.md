# 018 실험 B·C: 생성기 v3 데이터 + 27B 증류 (seed 2개)

## 질문
- B: 구조·스타일 축을 넓힌 합성 데이터(v3)를 더하면 다른 기관 문서 일반화가 회복되는가?
- C: 여기에 27B가 라벨링한 실제 문서(증류)를 더하면 더 좋아지는가?

## 판단 근거
- 014: 실패 원인이 긴 표·목록형 표·기관 스타일 부족 — 모두 합성 분포 문제.
- 017: 시퀀스 길이만 고쳐서는 해결되지 않음 → 데이터가 핵심.
- 증류: 27B는 모든 실제 세트에서 가장 안정적(0.955~0.985) → 실제 문서의 다양성을 직접 가져오는 가장 현실적인 방법.

## 해석
1. **v3 데이터(B)가 일반화 실패를 고쳤다.** 다른 기관 문서 0.805 → 0.926 (학습 전 0.900을 넘음), 긴 표 합성 0.80 → 0.98, 반복 붕괴(dev 잘림) 8 → 0. 두 seed가 거의 같은 값(0.925/0.927) → 우연이 아니다.
2. **증류(C)는 국회예산정책처 문서를 크게 올렸다** (0.955 → 0.979, 27B와 0.006 차이). 다른 기관 문서는 +0.007로 작다 — 증류 풀이 국회예산정책처 문서뿐이라 예상한 대로 **같은 기관 스타일에 주로 효과**가 있었다 (016 "계획 대비 변경").
3. 원본·보강 분포(test, ood)는 B·C 모두 유지.
4. seed 간 차이는 최대 0.017(C test_v3), 실제 문서 세트에서는 0.002~0.016 — 결론을 바꿀 크기는 아니다.
5. 남은 격차: 27B 대비 국회예산정책처 −0.006, 다른 기관 −0.038, 스캔 모사 −0.02~−0.03.
