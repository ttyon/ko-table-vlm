## 2. 증류 풀 (27B 가짜 정답 → 학습)
| 항목 | 내용 |
|---|---|
| 문서 | 국회예산정책처 「2026 대한민국 공공기관」(288쪽), 「2018회계연도 공공기관 결산분석보고서 1권」(204쪽) — 공공누리 제1유형 |
| 분리 | 모든 평가 문서와 **문서 단위로 다름**. test-real-3의 기관(관세청·재정경제부)은 쓰지 않음 |
| 페이지 | `(단위` 포함 페이지 전체 247쪽 (처음 각 75쪽만 샘플했다가, 표가 175개뿐이라 전체로 확대) |
| 표 | 294개 검출 → 페이지 단위로 **dev 42개(36쪽)** 분리, 학습 후보 **252개** |
| 교사 | Qwen3.8-27B zero-shot, 입력 긴 변 1280 |
| 필터 | 정상 종료 · 격자 일관 · 2행×2열 이상 · PDF 텍스트 레이어 대조 ≥0.95 |
| 필터 결과 | 252 → **224개** (격자 불일치 12, 텍스트 불일치 16 제거; 잘림·무효 0). 평균 9.5행, 최대 38행. 학습에는 2배 반복 = 448줄 |
| 라벨 정리 | 교사(27B)는 자간 헤더를 보이는 대로 띄어 씀(`구 분`) → 라벨 규칙대로 붙여 씀(`구분`), 224개 전부 적용 |
| 품질 점검 | 무작위 표 1개를 이미지와 대조: 구조 완벽, 셀 1개 오독(`농식품부`→`농림부`) — 필터 통과(대조율 0.987). **가짜 정답에는 1~2% 수준의 글자 노이즈가 남는다** |

## 3. 생성기 v3 (`gen_v3.py`, 015의 축 그대로)
| 축 | 구현 |
|---|---|
| 1 표 길이 | 통계표형 18~40행, 목록형 4~30행 (생성 결과 5~39행, 평균 25행) |
| 2 세로선 없음 | `no_vertical`, `dotted_v` 스타일 + 기존 테두리 |
| 3 빈 왼쪽 위 칸 | 통계표형의 60% |
| 4 L자형 헤더 | 통계표형의 50%: `만족(rowspan 2) + 빈칸(colspan 2) / 매우·약간` 등 일반 어휘 5종 |
| 5 구역 제목 행 | 값이 빈 행 또는 `< 제목 >` 전체 colspan 행 |
| 6 목록·문장형 | 2~4열, 코드 ID(`DT_818_A001` 형식), 글머리표 여러 줄 셀, 분류는 첫 행만(또는 rowspan) |
| 7 자간 라벨 | CSS `letter-spacing` 0.3~1.2em으로 렌더링, **정답은 붙여 씀** |
| 8 들여쓰기 | 같은 열 안 하위 항목 `padding-left` |
| 기타 | 각주 `2)`는 위첨자로 렌더링, 정답은 `… 2)` |

- 데이터: `train_v3` 3,000 (seed 21) · `val_v3` 200 (seed 22) · `test_v3` 200 (seed 23)
- 시퀀스 길이(이미지+프롬프트+정답): 평균 2,381, p95 4,286, 최대 5,534 토큰 → 6,144 안에 모두 들어감 (**2,048 기준이었다면 1,704개가 잘렸을 것**)
- 학습 데이터 B: 원본 3,000 + 보강 3,000 + v3 3,000 = **9,000** (seed 0 셔플), valid = 원본 val 300 + v3 val 200
- 학습 데이터 C: B 9,000 + 증류 224×2 = **9,448** (seed 0 셔플), valid 동일

## 4. 선택용 라벨 없는 dev
기존 17개(국회예산정책처 PDF, test-real에 안 넣은 표) + 증류 풀 dev 42개 = **59개**, 입력 1280. 잘림 수만 본다 (`scripts/select_ckpt2.sh`).
